# 우리동네 이웃살핌

혼자 계신 이웃이 걱정될 때 주민이 복지관에 알리는 앱.
길음종합사회복지관 마을동행팀 · 길음1동 / 길음2동 / 돈암1동 / 삼선동.

---

## 어떻게 도는가

```
주민이 앱에서 접수 → 접수 서버(앱스 스크립트) → 구글 시트 (담당자만 열람)
                                                    ↓
                                 담당자 확인 → 방문 → 주민센터 연계
```

**앱은 받기만 하고 아무것도 보여주지 않습니다.**
관리자 화면을 앱에 만들지 않은 이유는, 이런 정적 웹앱에는 진짜 로그인이 없어
비밀번호를 넣어도 소스만 열면 다 보이기 때문입니다.
**열람 통제는 구글 시트의 공유 권한으로 합니다.** 이게 진짜 자물쇠입니다.

## 파일

| 파일 | 하는 일 | 손댈 일 |
|---|---|---|
| `index.html` | 앱 전체 | 설정값 수정 시 |
| `sw.js` | 오프라인·설치 | 내용 고칠 때 버전만 |
| `manifest.json` | 앱 이름·아이콘 | 거의 없음 |
| `vercel.json` | 배포 설정 | 없음 |
| 아이콘 4개 | 홈 화면 아이콘 | 복지관 CI로 교체 시 |

## 배포 (처음 한 번)

### 1) GitHub에 올리기

github.com → 새 저장소 → **Add file → Upload files** →
파일 전부 끌어다 놓기 → **Commit changes**.

폴더째 말고 **파일만** 올리세요. `index.html`이 저장소 맨 위층에 있어야 합니다.

### 2) Vercel 배포

vercel.com → GitHub 로그인 → **Add New → Project** → **Import** → **Deploy**.

1분 뒤 주소가 나옵니다. 이게 주민에게 알려줄 주소입니다.
`Settings → Domains` 에서 알아보기 쉬운 이름으로 바꿔두면 좋습니다.

### 3) QR 만들어 배포

경로당 게시판, 아파트 엘리베이터, 통장님 통해 배포.
**종이에도 복지관 번호를 같이 찍으세요.** 스마트폰 없는 분들이 있습니다.

## 접수 켜기 (구글 시트 연결)

`ENDPOINT` 가 비어 있으면 접수하기를 눌러도 전화 안내만 나옵니다.
아래를 마치면 시트로 바로 쌓입니다.

### 1) 접수 서버 올리기

1. script.google.com 접속 (**반드시 기관 구글 계정**)
2. **새 프로젝트**
3. 코드 창을 다 지우고 `접수서버.gs` 전체를 붙여넣기
4. **저장**

### 2) 웹 앱으로 배포

1. 오른쪽 위 **배포** → **새 배포**
2. 왼쪽 톱니바퀴 → **웹 앱**
3. 설명 `이웃살핌 접수` / 실행 계정 **나** / 액세스 권한 **모든 사용자**
4. **배포** → 권한 요청이 뜨면
   계정 선택 → **고급** → **(안전하지 않은 페이지)로 이동** → **허용**
5. 나오는 **웹 앱 URL** 복사

```
https://script.google.com/macros/s/AKfycb..../exec
```

> 액세스 권한을 "나만"으로 두면 주민이 보낸 접수가 전부 거부됩니다.
> 이 주소로는 접수를 **보낼 수만** 있고, 시트 내용을 볼 수는 없습니다.

### 3) 앱에 붙여넣기

GitHub `index.html` → 연필 아이콘 → `ENDPOINT` 를 찾아 붙여넣고 Commit.

```js
const ENDPOINT = "https://script.google.com/macros/s/AKfycb..../exec";
```

이어서 `sw.js` 의 `VERSION` 숫자를 올리고 Commit.

### 4) 테스트

앱에서 성함 `테스트`, 사시는 곳 `테스트`, 추천 이유 아무거나,
추천하신 분에 본인 성함을 넣고 **접수하기**.

- **"접수되었습니다"** 가 뜨면 시트에 실제로 저장된 것입니다
- 실패하면 화면에 빨간 안내가 뜹니다 (조용히 사라지지 않습니다)

### 5) 시트 주소 확인

첫 접수가 들어온 뒤, 앱스 스크립트 함수 목록에서
**시트주소보기** 를 골라 **실행**. 실행 로그에 주소가 나옵니다.

### 6) 메일 알림 (권장)

`접수서버.gs` 의 `알림받을주소` 를 담당자 메일로 바꾸고,
`doPost` 안 `return 응답({ ok: true });` 바로 위에 한 줄을 넣습니다.

```js
try { 알림보내기(d); } catch (e) {}
```

고친 뒤에는 **배포 → 배포 관리 → 연필 → 버전 [새 버전] → 배포**.
새 배포를 만들면 주소가 바뀌니 반드시 기존 배포를 수정하세요.

## 시트 잠그기 — 가장 중요

> 이 앱은 **동의하지 않은 제3자의 성함·주소·연락처**를 수집합니다.
> 자원 정보와는 무게가 완전히 다릅니다. 아래를 반드시 지키세요.

- **절대 '웹에 게시' 하지 마세요.** 한 번 게시하면 주소만 알면 누구나 봅니다.
- 공유 설정을 **'제한됨'** 으로 두고 **담당자 2~3명만** 개별 초대.
- **기관 구글 계정**으로 만드세요. 개인 계정에 두면 퇴사 시 승계가 안 됩니다.
- 다운로드·인쇄·복사 제한 옵션을 켜두세요.

## 운영 규칙 (열기 전에 문서로)

**법적 근거.** 사회보장급여법의 지원대상자 발굴 신고 조항이 근거가 됩니다.
다만 공식 창구는 129와 주민센터이므로, **복지관 접수 건을 언제 공공으로
이첩할지** 기준을 정하고 주민센터와 미리 합의해 두세요.

**기관 내부 승인.** 이 기능은 기관의 개인정보 처리 범위를 넓힙니다.
**기관장 결재와 개인정보 처리방침 반영을 먼저 받으세요.**

**확인 주기.** 최소 주 2회. 담당자 1명 + 백업 1명.

**위급 건.** 앱이 119를 먼저 안내하지만 그래도 들어올 수 있습니다.
발견 즉시 어떻게 할지 정해두세요.

**보관 기간.** 1년 등으로 정하고 지나면 삭제. 처리 완료 건도 마찬가지.

**오남용 대비.** 이웃 갈등, 층간소음, 특정인 표적화 제보가 들어옵니다.
앱에 "다툼이나 소음은 주민센터로"라고 써뒀지만 완전히 막히지 않습니다.
담당자가 걸러내는 기준을 정해두세요.

**시범 평가.** 돈암1동에서 3~6개월. 접수 건수, 실제 발굴로 이어진 비율,
오남용 비율을 정리하면 확대 여부 판단 근거가 됩니다.

## 내용 고치기

GitHub에서 `index.html` → 연필 아이콘 → 수정 → **Commit changes**. 1분이면 반영.

고칠 만한 곳은 파일 맨 위 설정 구역에 모여 있습니다.

- `DONGS` — **네 개 동 설정 (이름·담당번호·주민센터·통 목록·지도)**
- `HELP` — 24시간 상담 번호
- `FLOW` — "알려주시면 어떻게 되나요" 5단계
- `HELPS` — "어떤 도움을 드리나요" 지원 활동
- `HOURS` — 업무 시간 (토요일 근무가 있으면 `days` 에 `6` 추가)
- `HELPS` 의 `photo` — **복지관 사진을 넣는 자리**
- `REASONS` — 추천 이유 네모 항목
- `CONSENTS` — 본인 연락 동의 선택지

### 일러스트 그림 넣기 (이미지 생성 AI로 만든 그림)

`FLOW` 와 `GUIDE` 의 **맨 뒤 칸**에 파일명을 적으면 코드 그림 대신
그 이미지가 나옵니다. 비워두면 지금처럼 코드 그림이 나옵니다.

```js
const FLOW = [
  ["이웃을 살펴봐 주세요", "설명…", "주민이 하시는 일", "eye", "flow1.jpg"],
  ...
];

const GUIDE = [
  ["며칠째 보이지 않습니다", "설명…", "absent", "sign1.jpg"],
  ...
];
```

- **5단계(FLOW)** — 가로가 긴 그림. 가로 1000px 안팎, 가로:세로 = 16:10
- **관찰 신호(GUIDE)** — 정사각형. 500×500px 정도 (동그랗게 잘립니다)
- 파일은 저장소 맨 위층에 올리고, 한 장당 300KB 아래로 줄이세요
- **13장을 모두 같은 화풍으로** 만드셔야 화면이 흐트러지지 않습니다

### 지원 활동에 실제 사진 넣기

지금은 색 그림이 들어가 있습니다. 복지관 프로그램 사진으로 바꾸려면
사진 파일을 저장소에 올리고 `HELPS` 의 `photo` 칸에 파일명을 적으세요.

```js
{ icon:"group", tint:"g", photo:"friend.jpg", title:"동네친구만들기", ... }
```

- `photo` 가 비어 있으면 색 그림이, 파일명이 있으면 사진이 나옵니다.
- **얼굴이 나온 사진은 당사자 동의를 먼저 받으세요.** 뒷모습이나
  손·음식 위주 사진이 안전합니다.
- 가로 800px 정도로 줄여 올리세요. 원본은 무겁습니다.

### 동을 추가하거나 고칠 때

`DONGS` 배열에 한 줄 넣으면 첫 화면에 바로 나타납니다.

```js
{ id:"jeongneung", name:"정릉동", tel:"02-0000-0000", dong:"02-0000-0000",
  tongs:["1통","2통","잘 모르겠어요"],
  map:"",                       // 동네지도 이미지 파일명 (없으면 빈칸)
  spots:[] },
```

- `id` 는 영문 소문자. 주민 휴대폰에 고른 동을 기억시키는 열쇠라
  **한 번 정하면 바꾸지 마세요.** 바꾸면 그 동 주민이 다시 고르게 됩니다.
- `map` 을 비워두면 그 동에서는 지도 메뉴가 안 나옵니다.
- `GUIDE` — "어떤 경우에 알려야 하나요" 안내문
- `FAQ` — 자주 묻는 질문

### 고친 뒤에는 반드시

`sw.js` 맨 위 `const VERSION = "v2";` 의 숫자를 올립니다. `"v3"`, `"v4"` ...

**빠뜨리면 이미 앱을 담아둔 주민 휴대폰에 옛날 내용이 계속 뜹니다.**

## 잘 안 될 때

| 증상 | 원인 |
|---|---|
| 접수하기를 눌러도 전화 안내만 뜸 | `ENDPOINT` 가 비어 있음 |
| 보냈는데 실패 안내가 뜸 | 배포 액세스 권한이 "모든 사용자"가 아님 |
| "홈 화면에 담기"가 없음 | 아이폰은 정상. 안드로이드면 이미 설치된 상태 |
| 고쳤는데 그대로임 | `sw.js` VERSION을 안 올림 |
| 파일 더블클릭하니 설치가 안 됨 | 정상. https 주소에서만 작동 |
